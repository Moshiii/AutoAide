Capture guidance:

- Prefer 16:9 desktop screenshots around 1440x900.
- Use realistic demo data, not lorem ipsum.
- Do not show secrets, tokens, private user IDs, real customer names, or personal messages.
- Keep the first screenshot focused on the main value: Feishu users can access a managed Codex-backed assistant.
